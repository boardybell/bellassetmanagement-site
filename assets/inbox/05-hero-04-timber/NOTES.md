## Grading

The raw PNGs preserve the untouched image-generation output. Both images are 1536 × 1024. Applied with the requested Python interpreter and Pillow; reproducible implementation is in `grade.py`.

Converted to luminance, applied 0.5% endpoint autocontrast, then a gentle 0.96 luminance exponent. Mapped the result through a continuous tritone: #14120F shadows → a midtone blend of 82% #6E6759 and 18% #8A6425 → #FDF6EC highlights. The midtone anchors at 50% luminance; interpolation is in RGB. This removes every source hue and confines output to warm neutral/brown palette interpolations.

Added fine independent monochrome grain uniformly distributed at ±2% of full-scale luminance before palette mapping, using fixed seeds 50401 and 50402. Applying grain before the color map prevents off-palette RGB noise. Clamped to the palette endpoints. Saved as full-size RGB PNGs without overlays, captions, resizing, or cropping.
